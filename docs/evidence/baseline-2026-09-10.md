## 9. Interpretación Forense — Hallazgos Clave

### 9.1 Presión Memoria Real
- **766 MB libre (10%)** = Windows gestionando presión activamente
- **opencode + Brave = ~4 GB WS combinado** = Legítimo pero alto
- **Standby estimado ~2.5 GB** = SysMain + file cache + prefetch inflando cache
- **Modified ~300 MB** = Escrituras pagefile pendientes
- **Compression Store estimado ~300 MB** = Kernel absorbiendo presión

### 9.2 Cuellos de Botella Identificados
1. **SysMain activo** → Llena Standby Priority 5 innecesariamente
2. **Servicios bloat ~150 MB** → Recuperables sin impacto funcional
3. **NDU activo** → Fuga non-paged pool conocida (50-200 MB)
4. **Pagefile 2GB min** → Límite commit ajustado (margen < 2 GB bajo carga)
5. **ReadyBoot no reconstruido** → Boots subsecuentes no optimizados

### 9.3 Acciones Prioritarias (Orden de Impacto)
1. **Desactivar SysMain** → Deja de inflar Standby
2. **Desactivar servicios bloat/telemetría** → ~150 MB WS recuperados
3. **NDU Disabled** → Fuga non-paged pool eliminada
4. **Pagefile 2/4 GB + Compression** → Margen commit seguro
5. **Límites duros WSL2/Docker/Node** → Prevenir acaparamiento
6. **ReadyBoot reconstruir (3 reboots)** → Boots tibios < 10s
